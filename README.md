# tarang-tj.github.io

My personal portfolio site. Hand-coded, single page, with an interactive 3D space scene: drag to rotate, then click the orbs to open slide-out panels for projects, experience, skills, and contact.

**Live:** https://tarang-tj.github.io

## Tech

- Vanilla HTML, CSS, and JavaScript, no build step.
- Three.js (r128, via CDN) for the 3D scene.
- Hosted on GitHub Pages from `main`.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.
